# 鱼类分类扩展实验 · 代码实现交接

交接给 6.2 sol。实验设计见 [further_exp.md](further_exp.md)。现有 CNN 已在项目虚拟环境跑通；下一步是在三个现有 Python 文件上实现预实验和实验。优先复用教学代码、数据读取方式和训练接口，保留原 CNN 的运行入口。

## 从哪里开始

| 文件 | 当前行为 | 待实现 |

解释器为项目根目录的 `.venv/bin/python`，环境已有 PaddlePaddle 2.6.2。图像位于 `data_set/fish_image/fish_*`，共 23 类、27,370 张。扩展实验使用独立的清单和输出子目录，避免覆盖已有 CNN 产物。

## 实施顺序

1. **固定数据。** 文件名形如 `fish_003486035363_11370.png`，中间数字串是轨迹编号。先按轨迹分组，兼顾各类样本量，再一次性写出三个集合的清单。划分比例尚未指定，可先按图像数约 80% / 10% / 10% 实现，记录各类实际图像数和轨迹数。核查三个集合轨迹两两无交集、样本总数正确、23 类均有覆盖。训练种子变化时复用同一份划分。
2. **接入网络。** 三个 ResNet18 变体统一采用适配 47×47 输入的首层（3×3、步长 1，省去首层最大池化），从随机初始化开始训练。在各残差块的残差分支末端、与捷径相加之前插入 SE 或 CBAM。SE 按通道加权；CBAM 先按通道再按空间加权。检查输出为每张图 23 个分数。现有 CNN 输出概率并使用 `CrossEntropyLoss(use_softmax=False)`；新网络若输出 logits，应配套使用接受 logits 的交叉熵。
3. **预实验选参。** 种子 42，分别训练 CNN、ResNet18 各一次，SE 的压缩比取 8、16、32，CBAM 用相同三个压缩比分别搭配 3×3、7×7 空间卷积核，共 11 次。固定 Adam、学习率 0.0005、5 轮、相同批大小与设备。现有训练批大小为 256，先验证本机能否承载最大的配置。用验证集宏平均 F1 在 SE 和 CBAM 各自的候选中选优，记录完整候选表及入选配置。若需处理同分，可预先约定优先验证准确率，再比较每步耗时。
4. **实验做对照。** 锁定配置，四组各用种子 43、44 再训练，共增加 8 次。复用预实验中对应的 4 个种子 42 模型，在同一独立评估集上评价四组各三个模型。总训练次数为 19。训练集和轮数与预实验一致，独立评估集只在选参结束后使用。

## 评价与交付

- **比较对象。** ResNet18 对比 CNN，两个注意力模型分别对比普通 ResNet18。按种子配对比较，汇总三个种子的均值与标准差。三组统一以 23 类宏平均 F1 为主，辅以总体准确率、各类召回率与样本数。混淆矩阵固定按标签 0～22 排列，便于追踪误判变化。
- **计时口径。** 统一训练设备、线程数和批大小。记录各训练步耗时并注明计时边界与预热步数，使用预热后的完整批次计算中位毫秒数。另记每轮及全程训练耗时，包含训练数据读取，评估和导出单独计时。
- **产物。** 建议在 `output/further_exp/` 下按模型、超参数和种子区分运行，保存模型、配置、验证指标和计时。另存预实验选参表、正式实验的逐次评估结果及四组汇总表。种子 42 的入选模型应可直接加载用于最终评估。
- **代码验收。** 在项目虚拟环境运行 `.venv/bin/python -m compileall -q src`，并对三个文件做静态检查。先用真实小批次验证四种网络的前向、更新、计时和保存后重新加载；用预测标签复核混淆矩阵总数与准确率。交付时补上实际可执行的入口命令，列明小样本验证和完整训练各自完成到哪一步。
